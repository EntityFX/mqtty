# MqttY — симулятор MQTT-брокеров и сетей

MqttY позволяет исследовать обмен сообщениями в сети MQTT без запуска настоящих брокеров. Симулятор исполняет клиентов, брокеры, сетевые задержки, очереди и протокольные обмены в модельном времени. Для воспроизведения измеренного брокера можно загрузить профиль, полученный из наблюдений MqttBenchmark.

## Что входит в проект

- **Ядро и MQTT-плагин** — модель времени, граф сетей, транспорт, клиенты и брокеры.
- **MqttRelay.App** — построение профиля брокера, BrokerFidelity и эксперименты с ретрансляцией.
- **LoadBalancing.App** — назначение MQTT-соединений одному или нескольким брокерам: DirectBalanced, Round Robin и Least Connections.
- **Federation.App** — сравнение центрального брокера, полносвязного Relay и статической федерации с подавлением повторов.
- **Designer** — графический редактор модельной сети на Avalonia.
- **Интеграционные тесты** — проверка протокольной модели, профилей, доставки и повторяемости.

## Быстрый запуск

Команда выполняется из корня этого репозитория. Нужен .NET SDK, поддерживающий сборку `net6.0`, и .NET 6 runtime. Designer использует .NET 8.

```bash
dotnet run --project src/EntityFX.MqttSimulator/EntityFX.MqttY.LoadBalancing.App -c Release -- demo --brokers 3 --mode roundRobin --publishers 12 --qos 1
```

Это идеальная демонстрация: профиль настоящего брокера и конфигурационный файл не нужны. Результат выводится в консоль; без `--output` файлы не сохраняются. Для профилированного опыта нужны проверенные наблюдения, точная конфигурация и отдельный каталог результатов.

Успешное выполнение модели и совпадение повторов не доказывают её точность относительно реального оборудования. Область применимости профиля проверяется отдельными натурными наблюдениями; CPU и RSS настоящего брокера автоматически не моделируются.
