# Документация MqttY

MqttY симулирует граф сетей, MQTT-клиентов и брокеров. Конкретные параметры поведения брокера поступают из внешней калибровки v3; сеть, время и ресурсные допущения задаются отдельно.

| Задача | Руководство |
|---|---|
| Подготовить Linux/Windows и .NET | [Подготовка машины](../../MqttBenchmark/docs/machine-preparation.md) |
| Измерить реальные брокеры | [MqttBenchmark](../../MqttBenchmark/docs/README.md) |
| Перенести raw/observations и создать calibration | [Калибровка v3](calibration-v3.md) |
| Запустить brokerFidelity или смешанную сеть | [Сетевые эксперименты](network-experiments.md) |
| Создать свою минимальную топологию | [Пример public API](custom-topology.md) |
| Понять ядро и профили | [Архитектура](architecture.md) |
| Оценить fidelity и ограничения | [Валидация](validation.md) |

[Общий маршрут](../../diss/doc/README.md) и [сохранённые результаты](../../diss/doc/results-and-evidence.md) дополняют этот индекс. Designer и разработка новых моделей ресурсов в пакет не входят. Руководства используют только внешний профиль v3; совместимость старого кода с другими профилями не является альтернативным маршрутом измерений.
